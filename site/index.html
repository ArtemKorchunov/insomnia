Why not just…

You've probably tried one of these.

Leave the lid open

The Mac stays awake.

The screen glows all night, and anyone who tidies the desk closes it and kills the run.

caffeinate or a keep-awake app

Stops the Mac from sleeping when idle.

Closing the lid still puts it to sleep, unless an external display is plugged in.

sudo pmset disablesleep 1

Really keeps it awake with the lid closed.

Nothing ever turns it back on. One night in a bag and it's hot and empty.

Insomnia uses the third one, and adds what it lacks: a watchdog that turns sleep back on when it's too hot, too low or too late, even after a crash.

Safety

It always gives sleep back.

A closed laptop in a bag is the worry. Insomnia checks every 30 seconds and puts the Mac to sleep as soon as any limit trips.

Thermal pressureHeavyRead from macOS with powermetrics. Heavy or worse means sleep now.
Battery temperature45 °CChange it with --max-temp.
Charge on battery20%Phone access has the same guard, so a forgotten laptop never drains to zero.
Your time limit1–12 hChange it while it runs, or add an hour. Phone access stops with it.

Cooling is never touched

Fans, SMC thermal control and CPU throttling work exactly as with the lid open. Insomnia only stops the lid and idle from putting the Mac to sleep.

Even a crash can't leave sleep off

A small login agent checks every minute. If sleep is still off with nothing watching it, after a kill -9 or a reboot, it turns sleep back on.

Phone access opens no ports

It uses Claude Code's own Remote Control, which only makes outbound HTTPS requests and never listens for connections on your Mac. You reach it through your own Claude account.

Passwordless only for what it runs

An optional rule allows just the exact pmset and powermetrics commands Insomnia uses, checked with visudo. The script itself never gets root.

Install

Three lines in Terminal.

It installs the insomnia command and builds the menu bar app into your Applications folder. Updates come from GitHub with one click in the panel, or automatically.

  • macOS 13 or newer on a MacBook, tested on Apple Silicon
  • Xcode Command Line Tools for the menu bar app
  • For phone access: Claude Code signed in with a Pro, Max, Team or Enterprise plan
Terminal
$ git clone https://github.com/ArtemKorchunov/insomnia.git ~/insomnia
$ cd ~/insomnia
$ ./install.sh
# later, from anywhere
$ insomnia on --hours 4 --remote all
$ insomnia update

Questions

Before you close the lid.

Is it safe to run a MacBook with the lid closed?

macOS keeps cooling it the same way, through the keyboard deck instead of the screen. Insomnia adds the limits macOS doesn't have for this case: it sleeps the Mac on Heavy thermal pressure, a battery above 45 °C, or a charge under 20% on battery. Keep it on a desk or a stand, not in a bag.

Do I need Claude to use it?

No. Without Claude it keeps any long job running with the lid closed: builds, downloads, renders. Phone access is the optional part, and it uses Claude Code's own Remote Control.

Will it ask for my password?

Changing sleep settings needs admin rights, so on and off ask once each time, and Touch ID works. Run insomnia install-nopasswd to allow only Insomnia's exact commands without a prompt.

What happens to phone chats when Insomnia turns off?

When the time limit runs out, phone access stops too, so a timed session ends fully. If you switch Insomnia off yourself, phone access keeps running while the Mac is awake.

Why do phone chats start from origin/main?

So a chat you start from bed doesn't land on whatever branch the folder had checked out. Each one gets its own git worktree. You can switch this off in Settings to work in the folder itself.

Does it cost anything?

No. It's free and open source under the MIT license.

Let the laptop sleep when you're done, not before.
